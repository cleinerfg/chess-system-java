# Sistema de Xadrez em Java

Projeto de um jogo de xadrez em modo console, desenvolvido originalmente no curso do professor Nélio Alves.

## Funcionalidades e Conceitos

* Arquitetura em camadas (Camada de Xadrez e Camada de Tabuleiro)
* Aplicação dos conceitos de Orientação a Objetos (Encapsulamento, Herança, Polimorfismo e Abstração)
* Tratamento de exceções personalizadas para regras e limites do jogo
* Movimentação de peças e validação de jogadas
* Regras especiais: Xeque, Xeque-mate, En Passant, Roque e Promoção

## Tecnologias e Melhorias

* Java
* Lombok: biblioteca adicionada para modernizar o projeto, reduzindo o código boilerplate com a geração automática de
  getters, setters e construtores.

## Como Executar

1. Certifique-se de ter o JDK instalado.
2. Compile o projeto na sua IDE de preferência ou via terminal.
3. Execute a classe principal (`Program.java`).
